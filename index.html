ℹ️ Acerca de Emprende Digital 2026

Sistema inteligente de gestión de proyectos, roles de startup escolar y gamificación para el Área de Educación para el Trabajo (EPT).

⚖️ Marco Legal: Ley 32172 — Regula el uso responsable de dispositivos tecnológicos en instituciones educativas de educación básica. El sistema está optimizado para su ejecución en las computadoras del laboratorio de cómputo del colegio, sin necesidad de teléfonos celulares.

Proyectos por Grado:

  • 1° Secundaria: Digitalización de Negocio Familiar (Canva Web / Carrd + WhatsApp)
  • 2° Secundaria: Digitalización de Servicios Locales (Canva Web / Carrd + Google Forms)
  • 3° Secundaria: App Web No-Code con Base de Datos (Glide Apps + Sheets + Canva)
  • 4° Secundaria: Tech Startup Escalable (Softr / Glide + Sheets + Canva)

Ecosistema de Roles y Red de Seguridad:

Cada equipo cuenta con 4 roles inspirados en empresas reales: CEO (Director Ejecutivo), CTO (Tecnología y Producto), CMO (Marketing y Branding) y CFO (Finanzas y Métricas). Si un miembro no puede asistir, el Rol Backup asignado asegura la continuidad del proyecto ganando puntos extra.
