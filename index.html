ℹ️ Acerca de este Dashboard

Dashboard estático de los proyectos de emprendimiento digital para 1° a 4° de secundaria.

Marco legal: Ley 32172 — uso de computadoras en IE, sin celulares.

  • 1° Secundaria: Digitalización de Negocio Familiar (Canva Web + WhatsApp)
  • 2° Secundaria: Digitalización de Servicios Locales (Canva + Google Forms)
  • 3° Secundaria: App Web No-Code con Base de Datos (Glide + Sheets)
  • 4° Secundaria: Tech Startup Escalable (Softr/Glide + Sheets)

Roles por equipo: CEO, CTO, CMO, CFO (con backups).

Duración: 6 semanas por bimestre.
